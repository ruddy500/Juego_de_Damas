Abrir con Visual Studio Code:

1 Descomprimir el archivo: Juego_de_Damas.zip
2 Abrir el Visual Studio Code
3 Abrir la Carpeta: Juego_de_Damas.zip
4 Abrir el archivo index.html
5 Ejecutar el archivo: index.html con la extension Live Server
6 Deberia abrirse el navegador con la pagina web ejecutada

Abrir sin Visual Studio Code:

1 Descomprimir el archivo: Juego_de_Damas.zip
2 Abrir la carpeta: Juego_de_Damas.zip
3 Ejecutar el archivo: index.html
4 Deberia abrirse el navegador con la pagina web ejecutada
