# Juego de Damas

## Ejecutar con Visual Studio Code

### Requisitos

- [Visual Studio Code](https://code.visualstudio.com/)
- Extensión **Live Server**

### Pasos

1. **Descomprimir** el archivo `Juego_de_Damas.zip`.

2. Abrir **Visual Studio Code**.

3. En Visual Studio Code, seleccionar:
   **Archivo → Abrir carpeta**.

4. Seleccionar la carpeta descomprimida:
   `Juego_de_Damas`

5. Abrir el archivo:
   `index.html`

6. Hacer clic derecho sobre `index.html` y seleccionar:
   **Open with Live Server**.

7. Se abrirá automáticamente el navegador con el juego ejecutándose.

---

## Ejecutar sin Visual Studio Code

1. **Descomprimir** el archivo `Juego_de_Damas.zip`.

2. Abrir la carpeta:
   `Juego_de_Damas`

3. Buscar el archivo:
   `index.html`

4. Hacer doble clic sobre `index.html`.

5. El archivo se abrirá en el navegador y podrá ejecutarse el juego.

---

## Nota

Si el juego no funciona correctamente al abrir directamente `index.html`, se recomienda utilizar **Visual Studio Code + Live Server**, ya que algunos proyectos web requieren ejecutarse mediante un servidor local.
